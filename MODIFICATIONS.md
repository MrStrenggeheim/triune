# Triune modifications

Triune is an independently maintained agent workspace based on Omnigent.
This record and the retained Git history identify inherited material and our changes.

| Source boundary | Reference |
| --- | --- |
| Upstream base | Omnigent `v0.20.0`, https://github.com/omnigent-ai/omnigent |
| Imported custom baseline | `4646d0bbd9492eed3bff0e95d39f8ac85d1b1eb8` |
| New product repository | https://github.com/MrStrenggeheim/triune, branch `main` |

The baseline includes the custom dockable workspace, independent resource views, Explorer, search, attachments, terminals, notifications and workspace controls.
Those previously Apache-licensed features retain their original permissions.

## Triune product changes — 2026-11-12

- Rebrand application, onboarding, CLI and current documentation as Triune.
- Preserve the approved three tilted strokes mark, accent palette and shared UI components.
- Add the primary `triune` command while preserving legacy command aliases, Python imports, environment variables and saved state compatibility.
- Install the backend and both SDKs from the Triune repository at the same ref.
- Keep the upstream Apache license and notices, and apply PolyForm Noncommercial 1.0.0 to new own material with required Triune attribution.
- Route live workspace-file references to the File Editor with configurable pane reuse, captured-original downloads and compact comment controls.
- Retain Explorer and transcript geometry through layout changes, reduce scrollbar rescans, and restore sidebar hierarchy and Git indicator consistency.
- Reuse shared density, notifications, workspace pickers and view-opening controls, and recover subchat quote creation without duplicating a failed child.
- Isolate retained-view updates, scope conversation subscriptions, batch native text, and pause hidden resource observation while retaining user state.
- Defer specialized viewers, retain reference originals as binary artifacts, and negotiate substantial JSON compression without changing streaming transports.
- Present attributed peer cards and compact lifecycle rows, with a flat Orchestration view and shared message actions.
- Preserve peer identity through native Codex echoes and resolve peer file references through their authorized source scope.

## Reliability and agent workspace — 2026-11-13

- Retain drafts while bounding live streams; preserve durable startup inputs and native consumption identity.
- Preserve dispatch-specific agent metadata and expose parent-owned child controls only when the runtime supports them.
- Reuse the original composer shelf, separate Orchestration agent/shell history, and open resources in tabs without inspectors.
- Keep tab overflow, close and pin controls usable at narrow widths.
- Open quote subchats before runner readiness, keep internal snapshots outside drafts, and fold inherited history on request.
- Replace per-frame text-background painting with opacity-based working highlights while preserving reduced motion.
- Retire older recoverable layout views, preserve protected editors and saved layouts, and schedule browser stream ownership with bounded snapshot catch-up.
- Render one stable task card and a distinct attributed Markdown reply, enriching late reports and preserving dispatch-specific source references.
- Simplify Orchestration rows, keep routine diagnostics internal, prefill captured Host/workspace and align natural-width semantic status badges.
- Bridge native asynchronous questions and long-running command lifecycle into the composer shelf, enable supported plan tools and capture named native delegations.
- Verify actual Codex and Claude capabilities through isolated CLI-to-browser journeys and preserve explicit-close guards while switching retained layouts.
- Replace idle-only activation with a durable session restart inventory and owner-authorized recovery of interrupted work after release health checks.
